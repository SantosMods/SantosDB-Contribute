## Resource Details {.tabset}

### Overview

A YMAP add-on on Great Ocean Highway. The README lists a taco truck, hot dog stand, burger stand, occasional spawning AI peds, a few random vehicles, trees, a hidden radar spot behind the sign, and bendable barrier reflectors.

The README says no additional resources are required and that it will not interfere with MLOs. The creator also sells the map on Tebex; this repository provides a ZIP.
