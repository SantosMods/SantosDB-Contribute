## Resource Details {.tabset}

### Overview

This repository holds siren packs and plugins for Luxart Engineering products. The README says plugins ship with each LVC:v3 and LVC:F resource release and are not meant to be downloaded from this repository.

The repository contains `Plugins` and `Siren Packs` folders. One visible siren pack is "Server Sided Mega Pack A (5+1)".
