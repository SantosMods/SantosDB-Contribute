## Resource Details {.tabset}

### Overview

RageUI is a FiveM menu library created as a replacement for NativeUILua-Reloaded.

It provides developers with APIs for building GTA Online-style menus.

RageUI is a general menu library and is not tied to ESX, vRP, or another roleplay framework.

### Development

The official repository includes:

* Menu source files
* Components
* Stream assets
* Builder files
* Tests
* `fxmanifest.lua`

### Known Issues

The official README documents a CPU calculation issue when menus contain very large numbers of items.

The documented example states that this processing occurs while the menu is visible.
