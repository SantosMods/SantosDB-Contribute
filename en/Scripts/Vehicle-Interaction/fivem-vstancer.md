## Resource Details {.tabset}

### Overview

`fivem-vstancer` is a FiveM resource based on ikt's VStancer. The README says it is built with the FiveM API and MenuAPI and synchronizes edited vehicles using decorators. Vehicles reset to default values stop being synchronised.

The default key to open the menu is `F6`.

### Features

* Edit track width
* Edit camber
* Edit tuning wheel size (needs a tuning wheel installed)
* Edit tuning wheel width (needs a tuning wheel installed)
* Manage presets
