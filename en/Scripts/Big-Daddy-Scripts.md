## Compatibility Checks

Big Daddy Scripts uses several symbols in its official compatibility table.

| Symbol   | Meaning                                                                                       |
| -------- | --------------------------------------------------------------------------------------------- |
| **✔**    | Verified working as a Stand-Alone resource. It is not implemented with the listed framework.  |
| **✅**    | Implemented with the framework and verified working.                                          |
| **⚠️**   | Expected to work, but functionality may conflict with the framework or its intended behavior. |
| **🚫**   | Not implemented or known to have major conflicts.                                             |
| {.dense} |                                                                                               |

> A **✔** next to QBCore, Qbox, or ESX does **not** mean the script is integrated with that framework. It means the Stand-Alone script has been verified to work without a known blocking issue. A **✅** indicates framework integration.
> {.is-warning}

For the current compatibility status of each script, use the official [Big Daddy Scripts Compatibility Checks](https://wiki.bigdaddyscripts.com/Documentation/Compatibility/).

## Compatibility Information {.tabset}

### Frameworks

The official Big Daddy Scripts website and documentation identify support across:

* Stand-Alone
* QBCore
* Qbox
* ESX

Support differs by resource.

Do not assume that framework compatibility means full framework integration.

### Integration

Framework-integrated scripts are identified with **✅** in the official compatibility table.

Depending on the resource, integration may involve systems such as:

* Money
* Jobs
* Inventory
* Targeting
* SQL
* CAD

These integrations are resource-specific.

### Stand-Alone Resources

A **✔** indicates that a Stand-Alone resource has been verified to work alongside the listed framework without a known blocking issue.

Stand-Alone compatibility does not automatically connect the resource to framework jobs, money, inventory, or other framework systems.

## Before You Install

* [ ] Find the resource in the official Big Daddy Scripts documentation.
* [ ] Check its current compatibility status.
* [ ] Confirm whether your framework is marked **✔**, **✅**, **⚠️**, or **🚫**.
* [ ] Read the resource-specific installation instructions.
* [ ] Check its required dependencies.
* [ ] Check whether it uses money, targeting, SQL, CAD, or ACE permissions.
* [ ] Keep the original resource folder name when instructed by the creator.
* [ ] Configure the resource using its official documentation.
* [ ] Check the server and client consoles after starting the resource.

> Some Big Daddy Scripts use resource-specific licensing, configuration, dependencies, or startup requirements. Follow the documentation for the individual script.
> {.is-warning}

## Framework Notes

> Always check the compatibility entry for the specific script before purchasing or installing it. Framework support is not identical across the Big Daddy Scripts catalog.
> {.is-info}

Big Daddy Scripts specifically distinguishes between:

**Compatible Stand-Alone scripts**

These may operate on a framework server but are not necessarily connected to that framework.

**Framework-integrated scripts**

These contain implementation intended for the supported framework and are identified separately in the official compatibility documentation.

This distinction is important for systems such as jobs, inventories, money, and other framework-managed features.
