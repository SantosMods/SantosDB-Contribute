## Resource Details

`lb-radioapp` adds a radio application to LB Phone.

The app lets players connect to radio frequencies and view a history of frequencies they previously connected to.

## Installation

### Installation Checklist

* [ ] Install `lb-phone`
* [ ] Download `lb-radioapp` from the authorized Cfx.re source
* [ ] Place it in your resources folder
* [ ] Start `lb-phone` first
* [ ] Start `lb-radioapp`
* [ ] Test radio frequency connections

```cfg
start lb-phone
```
