## Resource Details {.tabset}

### Overview

The README calls this FiveM's first open-source ASL menu, made for practising and using ASL in FiveM. All signs and animations are community-contributed.

### Features

* ASL letters A to Z and numbers 0 to 9
* Premade signs and sentences
* Sentence pre-structuring
* First-person view of other users signing
* Third-person signing

## Commands

| Command             | Purpose                                         |
| ------------------- | ----------------------------------------------- |
| `/asl`              | Sign to the nearest player with camera focus    |
| `/aslself`          | Practice mode with camera                       |
| `/asl2`             | Third-person signing                            |
| `/asldebug`         | Toggle debug mode                               |
| {.dense}            |                                                 |

Each signing command also accepts text to sign directly.
