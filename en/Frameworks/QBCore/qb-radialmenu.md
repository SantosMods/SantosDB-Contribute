## Resource Details {.tabset}

### Overview

`qb-radialmenu` gives players quick access to a menu for various actions. The manifest includes clothing, trunk, and stretcher modules.

### Requirements

* `qb-core`

### Features

* Radial menu interface
* Clothing, trunk, and stretcher client modules
* FontAwesome v5 icons configured by icon name in `config.lua`

## Configuration

Use the FontAwesome (v5) icon name in `config.lua`, without the `fa-` prefix or `#`. Example: `arrow-right`.
