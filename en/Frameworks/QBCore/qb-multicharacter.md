## Resource Details {.tabset}

### Overview

`qb-multicharacter` lets players create and choose between multiple characters. The README states that a default number of characters per Rockstar license can be set.

### Requirements

* `qb-core`
* `qb-spawn`
* `oxmysql`
* `qb-apartments`, `qb-clothing`, and `qb-weathersync` (listed by the README for the full character flow)

### Features

* Create up to 5 characters and delete any character
* See character information during selection
