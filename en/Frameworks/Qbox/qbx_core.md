## Resource Details {.tabset}

### Overview

`qbx_core` is the core of the Qbox Framework. The README says it was created on September 27, 2022, as a successor to `qb-core`.

It includes a bridge layer that provides backwards compatibility with most QBCore resources.

### Requirements

* `oxmysql`
* `ox_lib`
* `ox_inventory`

### Features

* Built-in multicharacter
* Built-in multi-job and gang support
* Built-in queue system for full servers
* Persistent player vehicles
* Export-based API to read and write core data
* Optional modules: Hooks, Logger (Discord or Ox logger), and Lib helpers
