## Resource Details {.tabset}

### Overview

The official README describes txAdmin as a web panel and in-game menu to manage and monitor FiveM and RedM servers, created in 2019.

### Features

* Recipe-based server deployer
* Start, stop, and restart the server or resources
* In-game admin menu
* Access control by Cfx.re login or password with an admin permission system
* Discord status embed and whitelist command
* Auto restart on crash or hang and CPU/RAM monitoring
* Player manager with warnings, bans, and whitelist
* Self-contained player database (no MySQL required)
* Scheduled restarts
* Server CFG editor and validator
