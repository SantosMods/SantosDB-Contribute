## Resource Details {.tabset}

### Overview

An addon for Lua Language Server (LuaLS). The README lists natives for GTA V, RDR3, and the shared CFX namespace regenerated weekly, runtime globals, manifest typing, and CfxLua syntax support. It replaces the discontinued `cfxlua-vscode` extension.

---

## Installation

### Installation Checklist

* [ ] Clone the repository to a permanent folder
* [ ] Set the `CFX_LUALS_ADDON` environment variable to that folder
* [ ] Add a `.luarc.json` to your resource as the README shows
* [ ] Restart your editor
