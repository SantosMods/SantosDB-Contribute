## Resource Details {.tabset}

### Overview

Sollumz is a Blender plugin for GTA V assets. The README lists import and export for YDD, YDR, YFT, YBN, YTYP, and YCD, plus partial YMAP support.

### Features

* Import and export
* Automatic texture loading
* Vertex colors
* Bones and weights
* Animations
* Custom normals
* Shader editing
