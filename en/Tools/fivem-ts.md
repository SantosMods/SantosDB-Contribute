## Resource Details {.tabset}

### Overview

A template for creating FiveM resources with TypeScript. It needs Bun and Git. The README offers `bun create`, the GitHub CLI, a repository template, or a direct download, then `bun install` and `bun run init`.

### Requirements

* Bun
* Git

---

## Installation

### Installation Checklist

* [ ] Install Bun and Git
* [ ] Create a project from the template
* [ ] Run `bun install`
* [ ] Run `bun run init` to set the project name
* [ ] Update `package.json` with author and repository information
