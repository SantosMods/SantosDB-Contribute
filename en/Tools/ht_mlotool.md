## Resource Details {.tabset}

### Overview

`ht_mlotool` helps customize and generate the files FiveM needs to handle audio occlusion for MLOs. The README shows General, Rooms, and Portals tabs.

---

## Installation

### Installation Checklist

* [ ] Download the latest release
* [ ] Place `ht_mlotool` in your resources folder
* [ ] Start the resource
* [ ] Use the General, Rooms, and Portals tabs to build occlusion files

> The README also describes building from source with pnpm (`pnpm i`, `pnpm build`).
