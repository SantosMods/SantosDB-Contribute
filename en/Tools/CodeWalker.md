## Resource Details {.tabset}

### Overview

CodeWalker views the contents of GTA V RPF archives. The README describes a world view, an explorer mode similar to OpenIV, and a project window for creating `.cwproj` projects and saving `.ymap` files for map mods. It also supports editing `.ynd` traffic paths, train track `.dat` files, and `.ymt` scenarios.

### Requirements

* PC version of GTA V
* 4 GB RAM (8 GB or more recommended)
* Windows 7 or newer, x64 processor
* .NET Framework 4.5 or newer
* DirectX 11 and Shader Model 4.0 capable graphics
